# CLAUDE.md

Quiz educativo em HTML puro sobre acentuação em português, com tema K-Pop. Projeto de alunos, orientado pelo professor Adilson.

## Regras do projeto

- Tudo fica em um único `index.html` (HTML, CSS e JavaScript). Sem frameworks, sem build, sem dependências.
- Idioma da interface e dos comentários: português do Brasil.
- O jogo é publicado no GitHub Pages a partir da branch `main`, pasta raiz.
- Imagens ficam em `images/`. Os nomes precisam bater exatamente com os do código (o GitHub diferencia maiúsculas de minúsculas).
- Cada pergunta da lista `perguntas` tem: `fase`, `grupo`, `imagem`, `pergunta`, `opcoes` e `correta` (posição da resposta certa, começando em 0).

## Cuidados ao alterar

- Mantenha o código simples e legível: os alunos precisam conseguir ler e editar.
- Ao mexer em perguntas, confira a resposta correta segundo o Novo Acordo Ortográfico.
- Não commitar fotos que os alunos não tenham permissão de publicar.
